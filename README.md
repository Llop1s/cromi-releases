# Cromi para macOS

**[Descargar la última versión](https://github.com/Llop1s/cromi-releases/releases/latest)**

- Mac con Apple Silicon (M1 o posterior): `Cromi-<versión>-arm64.dmg`
- Mac con Intel: `Cromi-<versión>-x64.dmg`

Abre el `.dmg` y arrastra Cromi a **Aplicaciones**. La primera vez macOS avisará de que no puede verificar el desarrollador: ve a **Ajustes del Sistema → Privacidad y seguridad** y pulsa **Abrir igualmente**.

Después Cromi se actualiza sola: descarga las versiones nuevas en segundo plano y las instala al cerrarla o al pulsar «Reiniciar y actualizar».

Este repositorio solo contiene las versiones publicadas.
